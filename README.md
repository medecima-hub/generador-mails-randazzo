# Generador de mails comerciales – Grupo Randazzo

Página web que arma los mails de **objetivos** y de **seguimiento semanal** por marca
(Kiara · Chevrolet, Peara · Fiat, Ciara · Renault), con **0KM** y **Planes de ahorro** por separado,
a partir de la planilla `Objetivos_Comerciales_Randazzo.xlsx`.

## Cómo se usa
1. Abrí la página.
2. Cargá la planilla (clic o arrastrar). Se lee en el navegador: **el archivo no se sube a ningún servidor**.
3. Elegí tipo de mail, empresa, unidad, período y fecha de corte.
4. Tocá **Copiar mail con formato** y pegalo en un mail nuevo de Outlook (Ctrl+V). Copiá Para y Asunto con sus botones.

La página no envía mails: solo los arma y copia.

## Contenido
- `index.html`: la aplicación completa (incluye SheetJS 0.18.5, licencia Apache-2.0, para leer Excel sin internet).
